# MPV Glass Lampa

Сборка медиаплеера MPV с темой оформления ModernGlass, настроенная для интеграции с Lampa Desktop и оптимизированная для качественного воспроизведения видео на Windows.

## Основные особенности

- **ModernGlass UI**: полупрозрачный современный интерфейс управления на базе скриптов `modernz` и `thumbz` с шрифтами Inter.
- **Интеграция с Lampa Desktop**: автоматический перехват фокуса и отображение иконки в панели задач Windows при запуске из Lampa (`scripts/bring-to-front.lua`).
- **Плавное воспроизведение**: включена интерполяция кадров (`interpolation=yes`, `tscale=oversample`, `video-sync=display-resample`, `vo=gpu-next`) для устранения микрорывков на ТВ и мониторах.
- **Удобное управление**: выход из полноэкранного режима по клавише `ESC` без закрытия плеера (`input.conf`).
- **Портативность**: поддержка как полностью автономного портативного режима (`portable_config`), так и установки в системную директорию `%APPDATA%\mpv`.

## Структура репозитория

- `portable_config/`
  - `mpv.conf` — параметры видео, вывода, рендеринга и фокуса.
  - `input.conf` — горячие клавиши.
  - `fonts/` — шрифты Inter для корректного отображения интерфейса.
  - `scripts/`
    - `bring-to-front.lua` — скрипт принудительного вывода окна на передний план и регистрации в панели задач.
    - `modernz.lua` — основной скрипт ModernGlass UI.
    - `thumbz.lua` — генерация превью таймлайна.
  - `script-opts/` — параметры темы и превью.
- `bin/mpv-portable.7z` — архив с бинарными файлами MPV для Windows.
- `install.bat` / `install.ps1` — скрипты быстрой распаковки и установки.

## Быстрый старт

### Вариант 1: Портативный запуск

1. Склонируйте или скачайте репозиторий.
2. Запустите `install.bat` (скрипт автоматически распакует `mpv.exe` в корень папки).
3. В настройках Lampa Desktop укажите путь к полученному `mpv.exe`.

### Вариант 2: Установка в системный профиль (%APPDATA%\mpv)

Запустите PowerShell и выполните:
```powershell
.\install.ps1 -InstallToAppData
```
Конфигурация будет скопирована в `%APPDATA%\mpv`.

## Настройка в Lampa Desktop

1. Откройте **Lampa Desktop** -> **Настройки** -> **Плеер**.
2. В параметре **Тип плеера** выберите **Другой**.
3. В поле **Путь к плееру** укажите абсолютный путь к `mpv.exe`.
